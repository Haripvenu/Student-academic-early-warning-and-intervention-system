# Academic Risk Monitor - Backend

FastAPI backend with supervised machine learning early warning pipelines for student retention.

## Features
- Modular REST API for cohort filtering, student risk profiles, intervention logging, and batch triage.
- Supervised multi-model classification (LightGBM, XGBoost, Random Forest, Logistic Regression) & risk scoring.
- Automated health check, database migrations, and SQLite WAL optimization.
